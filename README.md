# WhatHeThinks

女性向 AI Dating Chat Analyzer。上传 WhatsApp 聊天，看清男方的兴趣、投入与变化信号。

## 开发

```bash
npm install
npm run dev        # 本地开发
npm test           # 单元测试 (vitest)
npm run typecheck  # 类型检查
npm run build      # 生产构建
```
