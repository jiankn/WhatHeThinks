# 虚构 WhatsApp 测试聊天

仅供本地产品测试；姓名与对话均为虚构，非真实用户数据。日期格式均为 **月/日/年（MDY）**。

## WhatsApp-Emily-Jake-fictional.txt（降温型）

上传该文件，也可用同名 ZIP 测试压缩包导入。两个文件包含同一份记录。选择 **You = Emily**，**Him = Jake**。

故事覆盖 12 周：前 6 周男方常主动、回复较快、有具体约会；从 2026-08-03 起女方主动增多，男方回复变慢、变短、安排模糊，偶尔又表达想念。
英文对话适配当前英文产品。包含多行消息、表情、媒体占位与未接来电，不包含真实媒体附件。

## WhatsApp-Nora-Theo-fictional.txt（稳定正面型）

`scripts/generate-stable-chat.py` 生成，选择 **You = Nora**，**Him = Theo**。12 周内双方主动性各 50%、无冷却趋势，
用于测试报告与免费预览钩子在"积极稳定"读数上不编造问题（`analyze()` 应得到 0 个转折点、`interest.level = "strong"`）。
话题结构按周重复，衍生出一条跨十二周重复的台词，用来测试"反复出现的话"这条观察是否措辞谨慎。

两份记录都是为趋势与格式测试编写的合成数据，周内部分话题结构会重复；不代表自然聊天样本，不能用于评估模型真实世界准确率，也不保证固定分析结论。
